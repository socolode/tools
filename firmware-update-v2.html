💡 使用前必读 · 环境与连接说明 ▾
🌐浏览器要求：请使用电脑端的 Chrome / Edge 浏览器。本工具通过 Web 串口直连设备，不支持 iOS / Safari 手机浏览器。
三种操作，各需什么前置条件：
  1. 固件升级需要把设备进入「下载模式」（按住 BOOT 再插 USB），才能烧录固件。
  2. 读取当前固件版本普通连接即可，设备直接通过串口上报当前版本。
  3. 应用管理（同步 / 安装 / 升级应用）普通连接设备即可，通过串口读取设备上的应用列表。
如何进入「下载模式」：
  1. 拿起设备，按住摇杆的右方向键（BOOT 键）不动无需松开，保持按住。
  2. 把 USB 数据线插到电脑保持按住直到页面出现「已连接」。
  3. 松开按键，点击页面的「连接设备」下载模式与普通模式都能被识别，页面会自动区分。
连接要求：
  1. 使用数据线而非仅充电线部分线材仅供电，无法传输数据，会导致识别不到设备。
  2. 浏览器弹出串口授权窗口时，选择你的设备并「允许」
⚠️烧录风险提示：升级固件前请确认电量充足、过程不要拔线断电。一旦断电中断可能造成固件损坏，需要重新烧录。

🤔 如何进行固件升级 ▾
完整步骤：
  1. 进入下载模式按住摇杆右方向键（BOOT）不松，再插入 USB 数据线，等页面识别到设备。
  2. 点击「连接设备」浏览器弹出串口授权时选择设备并允许；连接成功后顶栏变为「已连接」。
  3. 读取当前版本页面会自动读出你设备正在运行的固件版本，并和最新版对比。
  4. 选择目标固件版本点击列表中的版本；已标记「最新」的即推荐版本，也可选择历史版本。
  5. 点击「开始升级所选固件」等待进度条走完，期间保持连接、不要拔线。
  6. 完成后重启升级成功会提示；断开 USB 重新上电即可使用新固件。
⚠️重要：升级过程中设备会重启进入 bootloader，请避免中途断线 / 断电 / 关闭标签页，否则可能损坏固件。
💡区分：若仅想「查看当前固件版本」而不升级，普通连接即可，无需进入下载模式。
✅升级固件不会删除你的应用和数据（应用在 SD 卡上），但为确保兼容，升级后建议到「应用管理」同步一次，检查是否有需要更新的应用。

🤔 应用管理 · 已安装 / 未安装 / 版本说明 ▾
什么是「同步」？
点击「连接并同步」后，工具通过串口读取设备 SD 卡中已安装的应用列表，与线上应用库比对，自动归入「已安装」或「未安装」。需要连接设备
「已安装」分组里的几种状态：
  1. 已最新设备上的版本已是最新，无需操作。
  2. 可升级设备版本落后于线上最新版，可点击「升级」按钮，或在下拉中选择想升到的版本。
「未安装」分组：
设备上尚未安装这些应用。点击「安装」即可安装，安装后可到「已安装」分组查看与管理。
版本下拉框说明：
每个应用都有一个版本下拉框，用于选择要升级到的版本。默认选中线上最新版；对已是最新的应用，仅显示当前版本。
📦应用也是升级包：升级 / 安装应用不影响固件，也不会影响其它应用的数据（每个应用的数据独立存放，卸载时一并删除）。
✅安全提示：应用安装 / 升级无需进入下载模式，普通连接即可完成，风险远低于固件烧录，可随时重复执行。
